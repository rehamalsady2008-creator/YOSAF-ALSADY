# دليل تشغيل وتصدير تطبيق "نور الإسلام" للهواتف الذكية (iOS & Android)

السلام عليكم ورحمة الله وبركاته،
هذا المشروع مبني بأحدث التقنيات (React 18 + TypeScript + Vite + Tailwind CSS + Capacitor) مع دعم كامل لوضع عدم الاتصال (Offline-First) والتعرف التلقائي على مساحات الأمان (Safe Areas) لجميع أجهزة iPhone و Android.

---

## 1. التشغيل السريع في بيئة التطوير (Local Development)

```bash
# 1. تثبيت الحزم والمكتبات
npm install

# 2. تشغيل خادم التطوير المحلي
npm run dev
```
سيفتح التطبيق على الرابط: `http://localhost:3000` أو `http://localhost:5173`.

---

## 2. تحويل المشروع لتطبيق Android أصلي (APK / Android Studio)

المشروع جاهز ومُهيأ مسبقاً باستخدام **Capacitor**:

```bash
# 1. بناء ملفات الإنتاج المجمعة
npm run build

# 2. إضافة منصة أندرويد (إذا لم تكن مضافة مسبقاً)
npm install @capacitor/android
npx cap add android

# 3. مزامنة الملفات وتحديث المشروع
npx cap sync android

# 4. فتح المشروع في برنامج Android Studio لبناء ملف APK
npx cap open android
```
- من داخل **Android Studio**: اضغط على `Build > Build Bundle(s) / APK(s) > Build APK(s)` لتحصل على ملف الـ APK النهائي القابل للتثبيت على أي جوال أندرويد!

---

## 3. تحويل المشروع لتطبيق iPhone أصلي (iOS / Xcode)

```bash
# 1. بناء ملفات الإنتاج
npm run build

# 2. إضافة منصة iOS (يتطلب جهاز Mac)
npm install @capacitor/ios
npx cap add ios

# 3. مزامنة ملفات الويب
npx cap sync ios

# 4. فتح المشروع داخل برنامج Xcode
npx cap open ios
```
- من داخل **Xcode**: اختر جهازك أو جهاز المحاكاة (Simulator) واضغط على زر التشغيل `Run (Cmd + R)`.
