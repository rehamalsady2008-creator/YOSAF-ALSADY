# تطبيق نور الإسلام (Noor Al-Islam)

تطبيق إسلامي شامل ومتكامل ومصمم ليعمل **100% بدون اتصال بالإنترنت (Offline First)**، ويدعم العمل كـ **تطبيق ويب تقدمي (PWA)**، أو **تطبيق أصلي للأندرويد و iOS** باستخدام Capacitor، أو **تطبيق ويب تفاعلي كامل**.

---

## 🌟 الميزات المضمنة في هذا المشروع:
1. **القرآن الكريم والتفسير الكامل**:
   - فهرس الـ 114 سورة كاملة مع محرك بحث فوري وتصفح الآيات والتفاسير.
2. **السبحة الإلكترونية المطورة (`TasbihSection`)**:
   - تصميم دائري ذهبي أنيق مع تفاعل اهتزاز وصوت، بطاقة الذكر والفضيلة، وأهداف قابلة للتخصيص (33، 99، 100، مفتوح).
   - سجل الورد والإحصائيات ورسم بياني لآخر 7 أيام.
   - إمكانية إضافة أذكار مخصصة وتخزينها محلياً.
3. **بوصلة القبلة وخريطة المسار الحي (`QiblaSection`)**:
   - مستشعرات حركة واقعية `DeviceOrientation API` مع فلتر تنعيم الحركة.
   - تحديد الموقع الجغرافي GPS تلقائياً ورسم مسار القبلة الكروي العظيم للكعبة المشرفة على خريطة متجهة.
   - كشف دقة المستشعر وميزة معايرة الحساس بحركة (8).
4. **مواقيت الصلاة والأذان والأذكار**:
   - حساب فلكي دقيق لمواقيت الصلاة اليومية.
   - حصن المسلم، أذكار الصباح والمساء، ومكتبة الأحاديث الشريفة.
5. **مساعد الذكاء الاصطناعي الشرعي**:
   - محرك استشارات إسلامية يعمل أوفلاين ومدعوم بالسيرفر.

## 🚀 تعليمات التشغيل والتثبيت المحلي (Local Development):

### 1. تثبيت الحزم والمكتبات:
```bash
npm install
```

### 2. تشغيل التطبيق في وضع التطوير:
```bash
npm run dev
```
سيعمل التطبيق على الرابط: `http://localhost:3000`

### 3. بناء المشروع للإنتاج (Production Build):
```bash
npm run build
```

### 4. تشغيل خادم الإنتاج:
```bash
npm run start
```

## 📱 التصدير والتحويل لتطبيق جوال أصلي (Android / iOS):

المشروع مهيأ ومزود بملف `capacitor.config.json` بالمعرف `com.nooralislam.app`.

### لتوليد تطبيق أندرويد (APK / Android Studio):
```bash
# 1. بناء ملفات الويب أولاً
npm run build

# 2. إضافة منصة الأندرويد
npx cap add android

# 3. مزامنة ملفات الويب مع مجلد الأندرويد
npx cap sync android

# 4. فتح المشروع في Android Studio لتوليد ملف APK أو رفعه لمتجر Google Play
npx cap open android
```

### لتوليد تطبيق آيفون (iOS / Xcode):
```bash
# 1. بناء ملفات الويب
npm run build

# 2. إضافة منصة iOS (يتطلب جهاز Mac مع Xcode)
npx cap add ios

# 3. المزامنة والفتح
npx cap sync ios
npx cap open ios
```

## 📦 بنية المجلدات في المشروع:
- `src/` : جميع الأكواد المصدرية والمكونات وصفحات التطبيق.
  - `src/components/`: مكونات الأقسام (القبلة، السبحة، القرآن، الأذكار، الصلاة، الإعدادات...).
  - `src/utils/`: محركات الحساب الفلكي، الإشعارات، والترجمة.
  - `src/types.ts`: تعريفات الأنواع لـ TypeScript.
- `public/`: الأصول العامة، أيقونات PWA، و `manifest.json`.
- `capacitor.config.json`: إعدادات تطبيق الجوال لـ Android و iOS.
- `server.ts`: خادم Express المدمج للتعامل مع الـ SSR والـ API.
- `package.json`: قائمة جميع التبعيات والمكتبات المستخدمة.
